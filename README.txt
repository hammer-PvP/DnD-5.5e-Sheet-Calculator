EN US D&D 5.5e Character Planner — Portable Beta 0.1.101

How to use:

1. Extract the ZIP file.
2. Double-click open character_planner.html.
3. The planner runs locally in your browser, no installation required.

Version Notes for Beta 0.1.101:
- Maintains the previous features of Beta 0.1.1.
- Homebrew rule for Background/Origin: free attributes.
- Choose +2/+1 or +1/+1/+1 on any attribute.
- Does not allow repeating the same attribute within the origin bonus.
- Feats defined in the Background remain fixed.
- This version is for manual validation.


Beta 0.1.101 EN-US notes:
- Applied spell hover tooltip/stat-block behavior across class spell choices and spell validation lists.
- Added cantrip progression dice lines where available.
- Preserved prior fixes: Thirsting Blade level gate, subclass progression panels, Battle Master maneuver selectors, EN-US content, and homebrew ASI rules.
